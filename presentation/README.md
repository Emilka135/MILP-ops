# Презентация как код

Локальный аналог скриптовой сборки Google Slides, без аккаунта Google и внешних API.
Содержимое и расположение элементов хранятся в `deck.json`. HTML, PDF, оба PPTX и
PNG собираются из него; экспортированные файлы **не являются исходниками**.
Никакие старые изображения или PPTX для сборки не нужны.

## Быстрый старт

Node.js 22+, Linux x64 (встроенный Chromium), команда из корня репозитория:

```bash
npm --prefix presentation ci
npm --prefix presentation run dev
```

Откройте `http://localhost:8787` **на своей машине**, либо живой предпросмотр Arena.
Сервер слушает `0.0.0.0` и принимает preview-host. Приложение не обращается к
браузерному `localhost` из удалённого предпросмотра: API относительный.

## Надёжный просмотр

Корень `/` — серверная PNG-галерея, без JavaScript и зависимостей от шрифтов,
масштабирования сцены и history API. Прямой переход: `/?slide=12`.
Кнопки «Назад» / «Далее» работают и при отключённом JavaScript.
`/editor#12` — отдельный браузерный редактор. Галерея показывает последнюю
сборку PNG; после правок выполните экспорт. Для первого запуска нужен `build`.

## Изменение прямо в браузере

1. Перейдите в `/editor`, выберите слайд слева.
2. Нажмите **«Править»**, затем нужный текст или фигуру.
3. Справа измените текст, размер, цвет, жирность, координаты или размеры.
4. **«Сохранить» / Ctrl+S** записывает изменения в `presentation/deck.json`.
5. **«Экспорт»** сохраняет исходник и пересобирает HTML, PDF, PPTX и PNG.
   Ссылки на результаты расположены под слайдом.

Стрелки ←/→ переключают слайды. Есть полный экран и заметки докладчика.
Сборка не автоматическая при каждом вводе символа — её запускает кнопка
«Экспорт» или команда `build`. Исходник сохраняется отдельно от экспорта.
Проверка границ не позволит сохранить элемент за пределами слайда.

Это небольшой локальный редактор, не многопользовательский сервис: последнее
сохранение побеждает. Не публикуйте сервер как публичный редактор и не вводите
реальные персональные данные. Для совместного доступа нужны аутентификация
и контроль версий. Демонстрация содержит только вымышленные данные.

## Изменение в коде

- `deck.json` — тексты, элементы, заметки, порядок слайдов и палитра `theme`.
- `src/styles.css` — общие стили, масштабирование и печать.
- `src/viewer.js` — рендер сцены и браузерный редактор.
- `lib.mjs` — проверка исходника и генерация автономного HTML.
- `build.mjs` — экспорт всех форматов.
- `assets/` — шрифты Noto Sans и лицензия; не скачиваются во время сборки.

Сцена — 1280 × 720, координаты и размеры в пикселях, размер шрифта в pt.
Цвет можно задать HEX-строкой или ссылкой на тему (`$teal`, `$ink`, `$paper`).
Пример элемента:

```json
{
  "id": "unique-heading",
  "type": "text",
  "x": 58, "y": 96, "w": 1152, "h": 140,
  "text": "Очередь на месяц.\nВрач сидит без пациента.",
  "size": 42, "bold": true, "color": "$ink"
}
```

Менять текст — править `text`. Общий акцентный цвет — `theme.teal`.
Добавить слайд — скопировать объект в `slides`, задать уникальный `id` и уникальные
ID элементов внутри него. `title` — подпись в навигации, `notes` — заметки докладчика.
Видимые номера слайдов — обычные текстовые элементы: при перестановке обновите их.

## Сборка и проверки

```bash
npm --prefix presentation run build
npm --prefix presentation test
```

Результаты — `docs/presentations/`:

| Файл | Назначение |
|---|---|
| `index.html` | Автономная презентация с встроенными шрифтами, без интернета |
| `clinic-voice-assistant.pdf` | PDF с текстовым слоем |
| `clinic-voice-assistant.pptx` | Совпадает с браузером: слайды-картинки, без зависимости от шрифтов |
| `clinic-voice-assistant-editable.pptx` | Отдельные редактируемые тексты и фигуры |
| `slides/slide-01.png` … | Скриншоты, полученные настоящим Chromium |

Для **редактируемого** PPTX установите Noto Sans из `assets/` на устройстве:
подмена шрифтов в PowerPoint может изменить переносы. Для гарантированного вида
используйте PDF или основной PPTX. Они строятся из одного браузерного рендера.

Перед экспортом шрифты полностью загружаются, текст вписывается в свои рамки.
Если переполнение осталось, сборка завершается ошибкой, а не скрывает текст.
Тесты проверяют данные, безопасность вставки текста в HTML, браузерный рендер,
навигацию, редактирование, мобильный экран и API. Эти тесты не подтверждают
медицинские или экономические гипотезы презентации.

Linux-сборка использует закреплённый Chromium из npm-пакета, а не скачивает
браузер с Google/CDN. На другой системе или для своего браузера задайте путь:

```bash
CHROME_PATH=/path/to/chrome npm --prefix presentation run build
```

Работа экспорта со своим Chrome на других ОС в этой среде не проверялась.
Первый запуск требует `npm ci`; после установки зависимости, шрифты и рендер
локальные. Код приложения поликлиники не зависит от Node.js: этот стек нужен
только для презентации.

## Состав презентации

В презентации оставлены только слайды 1–11. Региональный аудит и расчётные
примеры после 11-го слайда удалены из исходника и всех экспортов.
Исследовательские материалы `research.md`, `comparison.md` и `comparison.json`
сохранены отдельно как архив и не входят в презентацию.
