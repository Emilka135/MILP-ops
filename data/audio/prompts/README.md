Здесь находится постоянный банк статических фраз: manifest.json и WAV PCM16 mono 8kHz. Файлы создаются настоящим Silero при подготовке/запуске TTS, затем читаются с диска. Уникальные данные пациентов в этот банк не записываются. Для Docker используется отдельный volume audio-bank. Модель и голос входят в ключ записи; изменение текста создаёт новый ключ. Команда подготовки: python debug/build_audio_bank.py.
