# Разговор, архив и источники данных — 20.10.2026

Проверки выполняются на локальных Docker-контейнерах, localhost:8090 и :8080.

## Причины дефектов

- Мастерская читала только `learning_calls`; тестовые текстовые/голосовые разговоры лежали в отдельной SQLite и не попадали в список.
- Открытие шага зависело от текущего DSL. Удалённый исторический state приводил к ошибке, которую затем скрывал `openCall`.
- Семантические ответы не содержали намерения продолжения; имена врачей могли перехватывать вопрос идентификации.
- Поиск пациента завершался передачей оператору вместо повторного уточнения и ОМС.
- Сохранение DSL в редакторе теряло `listen field=...`. Сборщик использовал общий target и заменял локальный исполняемый файл версией из снимка. Исправлены сериализация и отдельный target/scenario-jobs; проверяется неизменность основного бинарника.

## Поведение

- Архив объединяет телефонные, текстовые, голосовые и загруженные разговоры с разграничением по линии. Новые телефонные архивы сохраняют версию графа. Для старых без версии показан только записанный путь, без выдуманных непосещённых веток.
- «Вы хотите записаться к офтальмологу?» требует ответа; отрицание передаёт оператору. Типы полей отделены от специальности. Ранее названное ФИО запоминается как неподтверждённое и перепроверяется.
- Полная дата рождения имеет календарную проверку и явные включительные границы, без возрастного порога 100 лет и догадки века. Частичный год требует уточнения. Нет совпадения: повтор ФИО/даты, затем ОМС.
- В левой панели с разделителем видны полный выполненный SQL, параметры, результат и источники. Запросы пока параметризованные, их не сочиняет LLM.
- Из исходных CSV/XLSX импортированы 35470 исторических записей, 17772 события звонков, 85 врачей, 136973 слота и 135 периодов недоступности. Снимок подключён read-only; выбор времени исключает занятые слоты и недоступность. Подтверждённая запись остаётся в отдельной тестовой таблице.

## Ограничения

В источниках нет ФИО/дат рождения пациентов, ОМС, прикрепления, участков, направлений и расшифровок. Эти данные нельзя восстановить из хэшей. Для идентификации используется обозначенная синтетическая картотека; без подтверждённой связи участка и врача запись к участковому блокируется. Это файловый снимок, не синхронизация с МИС.

Не выполнены все интеграции 15 исходных паспортов; см. debug/runs/dialogue-contracts/source-traceability.md. Экстренный резерв n дней не реализован: единица и количество резерва ещё не заданы. Персональное применение сценариев и обучение LLM не объявляются принятыми.
