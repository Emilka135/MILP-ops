# Произношение и качество речи

Штатные веса: **Silero v5_cis_base**, MIT, голос `ru_ekaterina`.
Источник: [официальный каталог](https://github.com/snakers4/silero-models/blob/master/models.yml), [MIT LICENSE_CIS](https://github.com/snakers4/silero-models/blob/master/LICENSE_CIS).
Размер 91 680 514 байт, SHA256 `ba41b18f6a707ad93605a162998865e7c087153d2e010a26dd02229dab0e672a`. Загрузчик сверяет этот SHA256. `v5_5_ru` больше не выбирается автоматически; её ограничение NC не исчезает от лицензии нашего приложения.

Ни акустическая модель, ни её название не гарантируют чтение сокращений и дат. Перед моделью работает общий `calls.tts.normalize`: `СМС`/`SMS` → «эс эм эс», `16.10.2026` → «шестнадцатого октября две тысячи двадцать шестого года», `14:30` → «четырнадцать тридцать», `201` → «двести один». Телефоны произносятся привычными группами, ведущие нули и номера карт — по цифрам. Невалидная дата или нераскрытый шаблон вызывают ошибку. Латинское имя требует явного русского произношения, вместо молчаливого удаления букв.

Для CIS base ударения автоматически добавляет локальный словарь. **Ручное ударение необязательно**: неизвестное слово передаётся в акустическую модель, а словарь учитывает его как диагностический пробел. Если звучание не понравилось, можно поставить `+` перед нужной гласной. `tools/check_prompt_stress.py` по умолчанию сообщает о пробелах без запрета запуска; `--strict` оставлен для явно запрошенного словарного аудита. Проверка смысла и фактического звука остаётся отдельной проверкой качества.

Синтез выполняется на 48 кГц с нейтральной скоростью. Затем FFmpeg `atempo` меняет темп с сохранением высоты; для телефона выполняется преобразование с фильтрацией до 8 кГц. Самописный WSOLA больше не участвует в рабочем синтезе. Для браузерной кнопки возвращается 48 кГц. Для звонка PCM остаётся 8 кГц: качество телефонной линии ограничено её полосой. Пиковый уровень ограничен без усиления фонового шума. Фраза синтезируется с воспроизводимым начальным состоянием акустического генератора.

## Проверка перед сборкой сценария

1. Администратор открывает «Аудиофразы» и обновляет записи из сценариев.
2. Нажимает **«Проверить произношение»**. Проверяется каждый текущий статический WAV: формат, длительность, уровень, клиппинг и фактическая расшифровка настоящим ASR.
3. Ошибки остаются в отчёте. Для каждого WAV сохранены ожидаемый текст, ASR-текст и SHA256. Нужные фразы прослушиваются и исправляются; затем проверка повторяется.
4. Сборка из редактора и отдельный сборщик требуют успешный актуальный отчёт. Изменённые текст, темп, WAV, модель или обработка требуют новой проверки. Черновики можно сохранять до проверки, чтобы не потерять работу.

`audio-bank/audit.json` — отчёт, `current.json` — текущая модель/голос/обработка. Старые версии остаются в банке, но не подменяют текущие фразы в интерфейсе. При замене WAV его прежняя версия сохраняется в `history/`.

Автоматический порог — WER ≤ 0,15 с отдельным точным сравнением числительных, месяцев, дней недели, отрицаний, ограничений до/после и статусов записи; ненулевой звук и отсутствие клиппинга. Версия политики `ru-clinic-critical-3`: старый сертификат не разрешает новый выпуск. Это фильтр ошибок, а не оценка естественности и не доказательство безошибочности каждой медицинской формулировки. Это не заменяет содержательную проверку и прослушивание. Ключ аудиобанка включает фактическое содержимое словаря ударений, реализацию accentor и выбранный fallback; удалённые фразы не отображаются как текущие.

## Воспроизводимый прогон

В ML-окружении должны быть установлены `requirements/tts.txt`, `requirements/asr.txt` и FFmpeg. GPU не требуется.

```bash
python tools/download_models.py --tts --asr
PYTHONPATH=runtime/src:. python debug/run_speech_quality.py --all-phrases --out debug/runs/tts-quality/verified
```

Предыдущий прогон 16.10.2026: **48/48** (42 постоянные фразы и 6 дополнительных примеров) прошли реальный TTS → WAV 8 кГц → ASR. В `debug/runs/tts-quality/verified/` для каждого примера находятся `*-48khz.wav`, `*-8khz.wav` и `result.json`. Этот набор включает ещё разрабатываемые сценарии; он не означает приёмку агента или ночных профилей. Этот отчёт предшествует строгому контролю ударений и новым сценариям; он не разрешает выпуск изменённого банка. Предыдущие неудачные сравнения голосов сохранены отдельно, не выданы за успешный результат.

Чтобы послушать:

- `01-sms-48khz.wav`: СМС;
- `02-date-time-48khz.wav`: дата, время, кабинет;
- `05-identifiers-48khz.wav`: номер карты и телефон;
- рядом одноимённые `*-8khz.wav` для сравнения телефонной полосы.

При миграции старого `.env` установите `TTS_SPEAKER=ru_ekaterina`. Прежний голос `xenia` относится к другой модели. Команда штатного запуска остаётся `./clinic start`. В Compose голосовой сервис зависит от успешного одноразового `audio-check`: тот вызывает настоящий ASR для текущих записей после готовности TTS/ASR. Проверка записей отделена от скачивания Python-пакетов и компиляции Rust.

## Исторический строгий контроль ударений, 18.10.2026

С 19.10 ручные отметки необязательны. Ниже сохранены прежние результаты; они не описывают текущую обязательность ввода.

```bash
PYTHONPATH=runtime/src:. python tools/check_prompt_stress.py \
  --out debug/runs/local-gpu/speech-ui/prompt-stress
# Новая фраза должна проходить тот же контроль:
PYTHONPATH=runtime/src:. python tools/check_prompt_stress.py \
  --text 'Врач Хачатур+ян принимает завтра.' \
  --out debug/runs/prompt-stress-extra
```

Проверяются корневые `scenarios/` после нормализации, статические части динамических шаблонов, все реплики пробного звонка, раскрытые сокращения и буквы, даты 2000–2099 и реальные входные фразы приёмки, включая «Да, конечно» и просьбу позвать оператора. На 18.10.2026: **155 фраз, 0 пропущенных слов**; отчёт `debug/runs/local-gpu/speech-ui/prompt-stress/result.json`. Значения пациента в шаблоне проверяются при фактическом синтезе. Добавление слова в словарь подтверждает покрытие, но само по себе не доказывает правильное ударение или естественность.

Короткая дата без года раскрывается только в явном контексте даты/приёма; неоднозначное `Значение 16.10` отклоняется. Знак минуса и ведущие нули сохраняются в произношении. Проверка смысла отдельно сверяет числа, календарные слова, отрицания, ограничения до/после и статус записи, даже при низком общем WER.

[Сравнить исправленные образцы 48/8 кГц](../debug/runs/voice-listening/corrected-listen.html): дата, СМС, каталог, фамилия с явным ударением и три голоса. [Метаданные и фактический ASR](../debug/runs/voice-listening/corrected-metadata.json) сохранены для семи примеров. Естественность и индивидуальное произношение фамилии остаются на прослушивании пользователя. Старый образец «Хачатурин» остаётся в первоначальном сравнении как неуспешный результат.
