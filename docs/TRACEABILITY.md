# Требование → реализация → проверка

| Требование | Реализация | Проверка / ограничение |
|---|---|---|
| Объединить два исходника | клонирован MILP-ops, добавлен runtime calls-arena; provenance.json | SHA256 архивов и исходный commit |
| Rust, модульность, параллельность | Rust VM / HTTP / очереди; Python чёрные ящики | cargo tests; 24 независимых HTTP-звонка |
| Редактируемые ветвящиеся сценарии | scenarios/*.flow → validated Rust match при build | компиляция останавливается при ошибке графа |
| DTMF сначала, ASR через 60 с | welcome.timeout → listen_free → speech transfer | тест timeout→speech; детекторы исходника |
| Оператор на любом шаге | * и safety-прерывание | тест во время идентификации; медицинский partial |
| Запись / перенос / отмена / статус | ClinicCrm, реальный контракт clients/visits | сквозные тесты, строгий HTTP-двойник |
| Нет ошибочного успеха | резерв + idempotency + подтверждение МИС | timeout after commit, гонка 16 писателей, restart |
| Подтверждение визита | локальный флаг | отдельного статуса в стенде нет |
| Направление за последний месяц | две отдельные ветви .flow | отсутствие/старое → оператор |
| Даты / числа / время | нормализатор calls-arena | unit-тесты и отдельный real-audio roundtrip |
| Малый агент + верификатор | TwoAgentNLU + MILP safety; optional USER-bge-m3 | в демо hash verifier; BGE не выдаётся за измеренный |
| Детерминированный текст→SQL | Rust rules/trie → параметризованные SELECT | bench-nlu, только allowlist; записи через диалог |
| Silero v5.5, скорость 1,3–1,75 | локальная модель, SSML + WSOLA | реальный синтез; замеры отдельно от симуляции |
| СМС с именем | постоянный outbox, повтор с Idempotency-Key | тесты имени, restart и дубликатов; нужен провайдер |
| Обзвон 3×2, 10–22 | общий per-phone бюджет в SQLite, GMT+4 | тесты границ и 6 попыток; нужен SIP-транк |
| Объявления и официальный телефон | подготовленный текст, конфигурационный gate | фактическая публикация клиникой не выполнялась |
| Контекст оператора + зелёные слоты | SQLite ticket + HTML + parameterised SQL | сохранение после restart, HTML escaping |
| 10 RPM и пагинация | один StrictStand + общий rate limit, pages по 50 | тесты исходника; реальные записи организаторам не отправлялись |
| 2026, Крылов, Deeray, лицензии | RESEARCH_ASR_2026 / RESEARCH_KRYLOV / LICENSES | неизвестная публикация явно отмечена |
| Расчёт GPU | capacity.py и формула compute/память/API | сценарная оценка; GPU не измерялся |
| Транскрипция и кластеризация записей | сохранён cluster_calls.py | аудиозаписей в архивах нет |
| ИИ-автоответчик / чужой получатель | identity перед reminder, verified отдельно от answered | настоящие аудиоответы не меняют запись до проверки карты |
| Сон операторов / обратный звонок | часы и доступность, callback.flow, SQLite callbacks и ticket | голосовой вопрос времени, сохранение; экстренный сигнал сразу |
| Раздельная проверка способов | debug/run_dtmf_commands.py и run_speech_commands.py | 0 ASR в тональном прогоне; 0 DTMF в речевом |
| Docker / CI / SCA / SBOM | Compose, GitHub Actions | функциональный Docker smoke и локальный Python SCA |

Исходное HTML требует естественную речь без цифрового меню, комментарии заказчика требуют DTMF первым и перевод речи после 60 секунд человеку. Приоритет отдан более конкретным комментариям; это осознанное отличие от базовой формулировки кейса. Измерений снижения неявок, удовлетворённости и потерь звонков на пациентах не проводилось.
