# Текст для публикации клиникой до обзвона

Перед публикацией замените квадратные скобки проверенными данными. Этот файл — подготовленный текст, а не сообщение о состоявшейся публикации.

> [Название поликлиники] напоминает о приёмах автоматическим звонком с номера [официальный номер]. Этот же номер указан на главной странице нашего сайта. Помощник предлагает подтвердить, отменить или перенести запись; сложные вопросы передаются регистратору. Мы не запрашиваем пароли, коды из СМС, данные банковских карт и денежные переводы. Если сомневаетесь в звонке, завершите его и самостоятельно перезвоните по номеру на официальном сайте. После записи или изменения визита вы получите сообщение с именем записанного пациента, врачом, датой и временем.

Публикация выполняется клиникой на её официальных площадках и главной странице. В конфигурации CLINIC_PHONE должен совпадать с опубликованным исходящим номером. ANTI_FRAUD_PUBLISHED выставляется после фактической публикации; исходящая кампания по умолчанию выключена.
