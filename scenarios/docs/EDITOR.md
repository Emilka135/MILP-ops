# Визуальный конструктор

Основа — React Flow (MIT), автоматическая раскладка Dagre (MIT), индекс поиска Fuse.js (Apache-2.0). Это редактирование настоящего `.flow` и его связей, а не изображение поверх ручного программирования.

```bash
cd scenario-editor
npm ci
npm run build
cd ..
PYTHONPATH=runtime/src python -m clinic.scenario_editor --allow-build
```

Открыть `http://127.0.0.1:8090`. Первоначальный пароль администратора — **admin** по указанию заказчика. Смена: `python tools/configure_admin.py`, затем перезапуск редактора. В контейнере путь задаёт `EDITOR_PASSWORD_FILE=/data/admin-password.json`; утилиту запускают с этим путём. Хеш scrypt хранится в игнорируемом `secrets/` или закрытом томе `/data`, не в сценарии. Телефонный `API_TOKEN` не авторизует редактор. HTTPS-прокси должен выставлять `EDITOR_SECURE_COOKIE=1`.

В большом сценарии по умолчанию показан линейный фрагмент: предыдущий шаг → текущий → до четырёх соседних вариантов. Кнопка «Ветки» раскрывает остальные варианты порциями. Нажатие на соседний блок продолжает чтение; поиск понимает и фразу, и полный идентификатор вроде `inbound.welcome`. Полный технический граф открывается кнопкой «Все блоки». У маленьких сценариев все блоки сразу помещаются на поле.

Слева выберите сценарий или создайте новый. Кликните/перетащите тип блока на поле. Соедините выход справа с входом слева; нажатие на связь открывает форму условия, включая клавиши телефона. Справа меняются фразы, операции МИС и параметры. Поиск работает по всем сценариям, включая несохранённый черновик; сервер также хранит индекс SQLite FTS5. Раскладка, масштабы и миникарта доступны на поле.

«Проверить» проверяет весь граф. «Сохранить» отклонит неверные ссылки или устаревшую ревизию. История позволяет восстановить версию. Импорт/экспорт JSON сохраняет расположение и подписи, `.flow` — исполняемый сценарий. Непринятый черновик хранится локально в браузере и предлагается при следующем входе.

В обычном контейнере тяжёлый компилятор выключен. Чтобы включить кнопку: `EDITOR_ALLOW_BUILD=1 docker compose --profile builder up --build -d scenario-builder scenario-editor`. Подробности и кэши: [BUILD_CACHE.md](../../docs/BUILD_CACHE.md).

«Собрать версию помощника» создаёт артефакт с ревизией сценария; работающие звонки используют прежний бинарник. После проверки новую версию устанавливают штатным обновлением: `docker compose up --build -d --wait orchestrator`. Дождитесь завершения активных звонков перед перезапуском; автоматического завершения живых вызовов кнопка сборки не делает.

Редактор не исполняет произвольные shell-команды пользователя. Вызов компилятора фиксирован и включается явно `--allow-build`; он ограничен временем и числом потоков. API изменения и полного графа требуют сессии администратора. Отдельная мастерская `/registrar` доступна наблюдателю без пароля; сервер запрещает ему любые изменения. Временный вход регистратора — `user/user`, рабочий номер `100`. [Инструкция мастерской](WORKSHOP.md). Ограничены размер проекта и число блоков; сохранение проверяет граф до замены файлов и восстанавливает исходники при ошибке записи.

## Приёмка в настоящем браузере

```bash
PYTHONPATH=runtime/src:. python -m pytest -q tests/integration/test_scenario_editor.py
node debug/run_editor_browser.mjs
```

Для Chromium нужен `CHROME_PATH` (по умолчанию `/opt/google/chrome/chrome`). Прогон создаёт изолированную копию сценариев в `debug/runs/editor-browser/` и не меняет рабочие сценарии. Проверяются вход/запрет анонимного API, создание, изменение фразы и DTMF, соединение мышью, поиск, сохранение и восстановление. Скриншоты и `result.json` сохраняются там же. Приложение проверено на 1600×1000. `node debug/run_editor_reading.mjs` отдельно проверяет ближайшие шаги, порции альтернатив, поиск по полному имени и переключение к полному графу; снимки — `debug/runs/editor-reading/`. Весь граф большого сценария по-прежнему требует масштабирования, поэтому он не является начальным режимом чтения.
