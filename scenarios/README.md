# Сценарии, регламент и работа сотрудника

Этот каталог — общий источник для автомата, справки кабинета, админского редактора и проверки CI. Действующие `.flow` лежат рядом с документацией; клиент читает их через `/api/workshop/knowledge` без обращения к МИС или LLM.

- `*.flow` — исполняемый конечный автомат. Администратор редактирует его существующим редактором; сохранение документа не устанавливает новую версию в активный звонок.
- [docs](docs/) — описание устройства, формы и проверки; [WORKSHOP](docs/WORKSHOP.md), [EDITOR](docs/EDITOR.md), [DOCX_TESTS](docs/DOCX_TESTS.md), [MIS_CONSTRUCTOR](docs/MIS_CONSTRUCTOR.md).
- [skills/people.md](skills/people.md) — инструкция сотруднику; [skills/ai.md](skills/ai.md) — правила для ИИ и разработчика.
- [reference/reglament.txt](reference/reglament.txt) — исходный документ; [reference/docx_index.json](reference/docx_index.json) — проверяемые ссылки на исходные случаи. Исходный текст не равен доказательству реализации.
- [mis/openapi.json](mis/openapi.json) — действительный контракт предоставленной МИС. Старые пути в `docs/` и `data/` сохранены совместимыми ссылками, а не вторыми копиями источников.

В контракте МИС нет направлений и сроков их действия. Поликлиника может отдельно включить собственный локальный реестр направлений; его источник и актуальность должны быть видны. Отсутствие такого реестра не означает ни «направления нет», ни «направление подтверждено». Исходные формулировки регламента про МИС не добавляют несуществующий endpoint стенду.

Кабинет позволяет написать и проверить черновик запроса по известной операции, увидеть недостающие/неверные поля и скопировать запрос. `/api/workshop/mis-draft` не делает сетевого вызова и не записывает пациента. Произвольный SQL из справки не исполняется; фактические операции выполняются через проверенные адаптеры и разрешённый сценарий.

Кабинет выписки направлений и упрощённая запись на анализы — отдельные предлагаемые расширения клиники. Сравнение стоимости исследований с двумя визитами может быть её организационным правилом; пациентские предложения ChatGPT сами по себе не подтверждают назначение или право на автоматическую запись. В текущий стенд эти возможности не добавлены.
