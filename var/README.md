# Этот каталог создаётся приложением при запуске (см. README, раздел 5).

Здесь появляются рабочие файлы, которые **не коммитятся**:

| Файл | Что внутри | Персональные данные |
|---|---|---|
| `mock_seed.json` | состояние оффлайн-стенда: вымышленные пациенты и записи демо | вымышленные данные стенда |
| `mock_stand.json` | оффлайн-стенд по умолчанию (засев из `app/mis/mock_stand.py`) | вымышленные данные стенда |
| `local_store.json` | локальный слой: подтверждения визитов, лист ожидания, заявки на дом, карточки перевода, отказы от обзвона | ФИО сокращены до «Фамилия И. О.», дата рождения — только год |
| `doctors_cache.json` | кэш справочника врачей из API стенда | нет |
| `token.txt` | **токен команды**, если вы выбрали этот способ вместо `.env` | секрет |
| `acceptance_report.json` | отчёт прогона 16 контрольных диалогов | нет |

Токен удобнее держать в `.env` (см. `.env.example`): он тоже не коммитится.
Каталог `var/` целиком исключён в `.gitignore`, поэтому случайно закоммитить
токен или рабочие данные невозможно.
