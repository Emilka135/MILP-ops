# Референсные источники кейса

Исходные CSV и XLSX перенесены из предоставленных файлов без изменения строк. `manifest.json` содержит размер и SHA256. Настройки нового редактора по умолчанию выбирают эти файлы в репозитории. Сохранённые пользователем адреса не перезаписываются.

Это файловый снимок. Подключение к МИС и SQL-шлюзу выбирается отдельно в настройках подключений; HTTP/HTTPS источники расписания и справки — в настройках источников. Данные пациента в истории приёмов представлены хэшами: по ним нельзя восстановить ФИО, дату рождения или полис. Полные телефонные номера в журнале замаскированы. Синтетические личности для тестового звонка находятся в `runtime/src/clinic/sandbox_fixtures.json`; референсная REST МИС реализована в `app/mis/mock_stand.py`.
