# Панель ответов МИС: приёмка UI

Ветка `feature/registrar-mis-panel`. Правую панель текущего/сохранённого звонка проверили настоящим Chromium; просмотрены `01-right-panel-archive.png`, `02-right-panel-live.png`, `03-narrow-panel.png`. HTTP-данные этого браузерного теста — явно синтетические fixtures. Тест не доказывает выполнение внешней МИС, TTS/ASR или модели.

## Проверено

- Панель справа от звонка при 1660 и 900 px; при 390 px располагается под звонком без горизонтального переполнения страницы.
- Поле, SQL, параметр, NULL, JSON, пустая строка, длинное значение копируются точно. Проверяется содержимое настоящего clipboard Chromium. Длинное значение прокручивается внутри ячейки и копируется целиком.
- Отказ Clipboard API переключается на настоящий `execCommand('copy')`. Полный отказ даёт видимое сообщение и возможность ручного копирования.
- Изменение ширины мышью и клавиатурой; пустой и несохранённый ответ; смена звонка; медленный старый ответ не заменяет выбранный звонок.
- Warnings телефонного архива остаются видимыми; SQLite названа тестовой; сохранённый результат не выдаётся за сверку с текущим состоянием МИС.
- Один компонент ответа используется также в раскрываемом журнале шагов и административной панели звонков. `ObserverCall.jsx` не изменён.

## Команды

`node debug/run_registrar_mis_panel.mjs` — 13 браузерных проверок, passed; ошибок JavaScript нет (`result.json`). Скрипт запускает только свой Vite на localhost, закрывает его и Chromium в finally. Нужен установленный Chrome (`CHROME_PATH` поддерживается).

`PYTHONPATH=runtime/src:. python -m pytest -q tests/integration/test_call_archive.py tests/integration/test_workshop_access.py` — 7 passed (`server-tests.log`).

`npm run build --prefix scenario-editor` — passed (`build.log`); остаются предупреждения upstream `use client` и размер JS chunk >500 kB.

`python tools/check_space.py` — passed до и после сборки (`space-after.json`).

## Остаток

Реальная интеграционная приёмка звукового звонка, производственной МИС, серверного конечного автомата и Actions относится к другим модулям. Размещение правой панели в административном CallsPanel собрано, но отдельный административный браузерный вход этим скриптом не проверяется. Разрешения, которые даёт UI тесту синтетический HTTP fixture, не служат проверкой серверной авторизации: для неё выполнены отдельные 7 серверных тестов.
