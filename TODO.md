# Незавершённые правки

Обновлено 15.10.2026. Это список обязательств, а не перечень готовых возможностей. Полные условия модулей: [GOAL.md](docs/acceptance/GOAL.md). Пункт закрывается только с фактической проверкой; переключение задачи не снимает обязательство.

## Сейчас: речь и проверка каждого сообщения

- [ ] Перевести штатный TTS с v5_5_ru (ограничение NC) на подходящую разрешительную лицензию, зафиксировать официальный источник, лицензию и SHA256 весов.
- [ ] Нормализовать перед синтезом СМС/SMS, ФИО, ОМС, СНИЛС, названия исследований, даты, время, числа и телефонные номера; неоднозначное не угадывать.
- [ ] Устранить артефакты ускорения/пересэмплирования; сохранить для сравнения исходный голос высокого качества и телефонный WAV.
- [ ] Проверять весь текущий аудиобанк до разрешения сборки/развёртывания: расшифровка настоящим ASR, длительность, тишина, клиппинг, отчёт по каждой фразе. Непроверенные/ошибочные фразы блокируют выпуск.
- [ ] Для динамических реплик проверить шаблоны с датами, цифрами, фамилиями; отсутствие ошибок статики не доказывает корректность динамики.
- [ ] Дать послушать реальные образцы. Субъективное качество не выдавать за доказанное метрикой RMS или ASR.
- [ ] Проверить кнопку «Озвучить сообщение» в админке и мастерской настоящим воспроизведением в браузере; показать понятную ошибку недоступного TTS.

## Интерфейс и доступ

- [ ] `admin/admin`, временный регистратор `user/user`; без пароля — наблюдатель с просмотром дерева и детализации звонка. Проверить серверные запреты записи и изоляцию номера регистратора.
- [ ] Регистратору оставить текущий шаг, предыдущий и непосредственных соседей; последовательный игровой путь без глобальных стрелок.
- [ ] Админу сделать основной маршрут линейным и читаемым, ответвления — рядом; минимизировать пересечения, крупные сценарии раскрывать по частям. Проверить скриншотами.
- [ ] Проверить создание учётной записи через форму админа, выход и повторный вход, отсутствие ошибок браузера.
- [ ] Опубликовать проверенный модуль мастерской отдельным подписанным коммитом; сейчас изменения в рабочем дереве.

## Обучение, отзывы, ночные изменения

- [ ] Довести архив реального разговора и маршрута, простые поля разметки и «Ответить раньше»; при отказе CRM не терять архив.
- [ ] Подключить ночную обработку к общему расписанию и проверить контейнером после закрытия.
- [ ] Довести утверждение администратором, проверяемый артефакт ревизии, включение только для номера автора со следующих суток, срок действия и откат.
- [ ] Подключить проверенные альтернативные формулировки к NLU; безопасно активировать изменение ответа и порядка с проверкой необходимых данных.
- [ ] Подключить сбор «Что исправить в тестовом варианте?», жалобы, приостановку профиля, кластеризацию и просмотр админом.
- [ ] Сравнивать реальные результаты версий: успех, ошибки, жалобы, повторные обращения; учитывать объём и сложность выборки.

- [ ] Проверить ограниченного агента на настоящем голосовом пути: только реальные слоты трёх дней, всего три предложения, клавиши 1/0/2, подтверждение только после МИС.
- [ ] Исправить бюджет таймаутов OpenRouter, валидацию всех типов решения, фильтр времени до ограничения трёх дней, направления по данным БД.
- [ ] Ключ модели хранить локально; отдельно указать, вызывалась ли настоящая LLM, не подменять её детерминированным тестом.
- [ ] Оператору передавать тот же контекст, запрос/параметры и слоты; очередь и ожидание сообщать по данным, без выдуманных минут.
- [ ] Довести безопасную смену МИС из админки с изоляцией идентификаторов и скрытыми секретами.
- [ ] Проверить неизвестный номер («Вы у нас впервые?»), неизвестного ответившего и ИИ-автоответчик без разглашения данных.
- [ ] Проверить финальное подтверждение, СМС, возражение, благодарность и молчание; повторить независимые ASR/DTMF/совместные прогоны.

## Очередь и подготовка

- [ ] Принять исследования и каталог подготовки: источники, дата, клиническое утверждение; выключенные/просроченные инструкции не использовать.
- [ ] Довести оценку ожидания по наблюдаемым данным с незавершёнными запросами; не выдавать норматив за среднее по региону.
- [ ] Подключить адаптивный срок напоминания и кампанию освобождённых слотов к фактическому обзвону.
- [ ] Исправить конкуренцию предложений, стабильный offer_id и истечение; сначала ближайшие более поздние записи, затем согласившаяся очередь.
- [ ] Проверить подготовку до предложения, сохранение старой записи при ошибке/отказе и прекращение обзвона после согласия одного.
